# Mentor extraction — free advice most teams waste

## The map

- **Sponsor engineers** — often judge their own prize. Demo to them during office hours = pre-judging feedback from a literal judge. Ask "does this satisfy your prize criteria?"
- **Organizer mentors** — know the venue, the wifi, the deadline gotchas, which requirements are enforced vs stated.
- **Domain mentors** — only useful for the problem-space question you can't google. Skip them for stack help.

## How to ask

- Specific questions only: "does the API return X at scale" not "what do you think?"
- 5 minutes, then back to building. A mentor conversation is not progress — the fix after it is.
- Hit sponsor booths in hour 1-2 for API quirks and hidden rate limits; that's when they remember you.

## What to take

- Any prize-relevant clarification → write it into `recon.py` input immediately.
- Any rule contradiction → write it into `check.py` input.
- Nothing else. Mentors optimize for being helpful-feeling, not for your demo.
